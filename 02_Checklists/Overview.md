**Registration Checklist**

This checklist was created based on the available functionality of the Customer Registration form. Since detailed requirements and validation rules are not provided, the expected results are based on the available application behavior and common validation practices. Any observed behavior that is not specified in the requirements is documented in the Comments column.

**Assumptions**

This project is based on the publicly available Toolshop Demo application.
The application does not provide a complete functional specification or detailed validation rules. Therefore, the expected results are based on:
- visible UI requirements;
- common web application usability principles;
- exploratory testing;
- observed application behavior.
Where requirements are missing, observations are documented in the Comments column instead of treating the behavior as a defect.

**Known Limitations**

The application documentation does **not specify**: 
- minimum and maximum length for most text fields;
- supported character sets;
- allowed special characters;
- whitespace handling;
- input trimming behavior;
- validation rules for names and addresses.
These scenarios were explored during testing, and the observed behavior is documented in the checklist.
